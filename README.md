# 离线电子记账本（PWA）

一个**断网也能用**的智能记账本，专为「按客户固定类目 × 每日数量」月结的生意设计（例如洗涤厂结算表）。
装到手机/电脑桌面即可像 App 一样使用：记一笔、批量导入、核销对账、一键导出 Excel 结算表，联网后自动同步云端。

> 核心卖点：**离线优先** · **粘贴即记账** · **一键结算表** · **多端同步** · **错单可追溯**

## ✨ 功能一览

| 功能 | 说明 |
| --- | --- |
| 📄 记一笔 | 选客户后按固定类目直接填数量，自动计价并转人民币大写；可快捷新增类目并永久保存到该客户 |
| 📋 明细管理 | 按月查看账单，支持按客户/类目/单号/备注搜索与核销状态筛选；可核销、撤回、编辑、删除（已核销单据需管理员口令） |
| 🧾 电子单据 | 生成可打印/截屏发送给客户的收款单，含合计大写与核销状态 |
| ⚡ 智能批量导入 | 仿快递粘贴识别：一次粘贴多个客户的微信报数文本，自动识别客户、日期（今天/昨天/11月21日等）、类目、数量、单价；不存在的客户自动建档，重复账单自动拦截 |
| 📊 结算统计 | 实时预览「类目 × 1~31 日」横向矩阵与总计，1:1 还原传统结算表版式并导出 Excel；每个客户可定制专属表头、筛选范围、尾列、签字栏、明细附表 |
| 👥 客户设置 | 管理合作客户、固定类目与专属单价（增删改、排序）、结算表默认抬头 |
| 👮 管理员后台 | 口令进入，修正错误的数量/单价（含已核销锁单），每次修改自动写入审计日志；可修改管理员口令 |
| ☁️ 云同步（可选） | 接入 Dexie Cloud（有免费版）：邮箱验证码登录，手机/电脑同账号同步；离线期间的数据联网后自动补传 |
| 💾 备份恢复 | 一键导出/导入 JSON 全量备份，换手机可完整恢复；备份文件不包含管理员口令 |
| 📱 PWA 安装 | iOS「添加到主屏幕」/ Android「安装应用」后全屏运行，Service Worker 自动更新 |

## 🚀 快速开始

要求：Node.js 22+

```bash
npm install     # 安装依赖
npm run dev     # 本地开发（默认 http://localhost:5173/ios-offline-ledger-pwa/）
npm run build   # 生产构建（输出到 dist/）
npm run preview # 本地预览构建产物
```

> 未配置云端时，应用以**纯本地模式**运行，所有数据保存在本机浏览器（IndexedDB），功能完整可用。

## ☁️ 云同步配置（可选）

两种方式任选其一：

1. **构建时注入**：复制 `.env.example` 为 `.env`，填入
   ```bash
   VITE_DEXIE_CLOUD_URL=https://你的数据库.dexie.cloud
   ```
2. **应用内配置**：打开「客户设置 → 云端账号同步」，粘贴地址保存后刷新即可。

云数据库可通过 `npx dexie-cloud create` 免费创建。首次使用 CLI 会在本地生成 `dexie-cloud.json` / `dexie-cloud.key` 管理文件（已加入 `.gitignore`），请勿将 key 提交或公开泄露。

- 切换地址时可准备一份本机迁移快照。在目标云库登录后，回到「云端账号同步」预览并合并待迁移账本。源账本仍可通过原地址或本地模式打开。
- 云同步提示会话过期时，使用「重新验证当前邮箱」。退出登录会清理该云库在本机的副本，退出前应确认同步完成或先导出备份。

## 👮 管理员后台

- 入口：「客户设置 → 管理员后台」或已核销单据上的「管理员纠错」。
- **默认口令：`8888`**，首次使用后请立即在「口令与同步」中修改。
- 口令以加盐哈希形式保存在本机独立数据库。升级会迁移设备读到的旧口令，此后设备各自保存口令。使用过旧版本的设备应设置新 PIN。
- PIN 用于防止本机误操作。多人协作时，每位操作员应使用自己的云账号，由云库管理员在 Dexie Cloud 中配置数据共享和角色。共享同一个邮箱账号无法区分操作员与管理员。

## 💾 数据与安全

- 数据存储于浏览器 IndexedDB（数据库 `OfflineLedgerCloudDB`），并申请持久化存储权限，降低被系统清理的风险。
- 快速双击不会重复记账。同一份本机数据库中的并发编辑有版本校验，两台离线设备之间的同步冲突由 Dexie Cloud 处理。
- 恢复备份时先校验文件并预览新增数量，合并只添加缺失记录，现有账单及客户模板优先。新版备份包含纠错审计记录，管理员口令和云库归属字段不随文件迁移。
- 月结表和 Excel 按已保存的账单金额汇总，将分币尾差分配到类目，确保类目合计与账单合计一致。

## ❓ 常见问题

**Q：换手机后数据怎么办？**
两种方式：① 登录同一个云账号自动同步；② 「客户设置 → 本地离线数据备份」导出 JSON，在新手机导入恢复。

**Q：断网时记账会丢吗？**
不会。所有操作先写本机数据库并标记「待上传」，联网且已登录后自动补传。

**Q：删除客户会删掉历史账单吗？**
不会。只删除客户档案与类目，历史账单保留。

**Q：忘记管理员口令？**
口令以加盐哈希存储，无法找回。可先导出 JSON 备份，再清除本应用的站点数据重新初始化（默认口令恢复为 `8888`），然后导入备份恢复数据；若开启了云同步，请在重新登录云账号前先改好新口令。
